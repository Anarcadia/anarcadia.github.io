核心特性与设计细节

  • 全域 0px 纯直角与 1px 炭黑外露网格

    彻底移除圆角与弧脚，所有 Tab、按钮、输入框与弹窗均为干脆利落的直角矩形；1px solid #181B18 实线贯穿切分左右侧栏、Tab、大纲与表格，重现瑞士网格秩序感。

  • 三阶暖色印刷纸底拉开空间景深

    中央道林浅灰纸 (#ECEAE2) → 侧栏旧报刊中暖灰 (#E2DFD5) → 右上大纲亚麻深暖灰 (#D6D2C6)，无需阴影模糊即可自然区分工作区层级。

  • 松绿强调色 + 3px 纯色硬边阴影

    竹青浓绿 (#78AB88) / 深松墨绿 (#26593F) 搭配零模糊纯色硬边偏移阴影 (3px 3px 0px #A3C9AE)，贯穿引用块、Callout、代码块与按钮。

  • 阅读态 / 编辑态双模式字体分离 + 粗体三重强化

    阅读态调用锐利现代印刷黑体（vivo Sans），编辑态切为 2:1 等距打字机体（Sarasa Mono Slab SC）；粗体叠加 750 ExtraBold、深墨松绿字色与 1.5px 细压线。

安装与快速上手

极简安装：Obsidian 官方商店搜索 chuanban-green（简装版）

字体安装到系统字库后完全退出并重启 Obsidian，主题内置 @font-face 探针会自动识别接管，无需手工填写字体名。

OBSIDIAN STORE · 安装与个性化调节 
1. 打开 Obsidian → 设置 (Settings) → 外观 (Appearance) → 主题 (Themes) → 管理 (Manage)
2. 搜索：chuanban-green → 点击「安装并使用」
3. (可选) 安装社区插件 Style Settings → 进入 chuanban-green (松绿记事本)，自由切换激活 Tab 配色（竹青浓绿 ⇄ 深松墨绿）、三套正文字体预设与硬边阴影偏移。
安装提示：若下载全装版中的 vivo Sans（9 字重）与 Sarasa Mono Slab SC 字体包，安装进系统字体册后请完全退出并重启 Obsidian，主题将自动探针接管。
