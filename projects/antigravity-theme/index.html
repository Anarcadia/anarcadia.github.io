核心特性与设计细节

  • 多套深度调教皮肤，绝非简单换色

    「草墨石砚」负责清新愉快，「莫兰迪古典矿物风格」负责典雅、书卷暖白风格「Absolutely！」负责 Claude 味儿、「温润书卷夜间风格」与「幽林深色」负责夜晚护眼；提供独立的「跟随系统」自动日夜配对开关，支持一键切回官方原版冰蓝色皮肤。

  • 2,371 条母语级汉化与中英一键双切

    内置 2,371 条自然中文汉化（覆盖主界面、斜杠命令、设置项、编排器与 Swarm 子 Agent 面板），严格隔离代码块与凭据避免误翻；提供 [ EN | 中文 ] 独立按钮，随时一键退回英文。

  • 字体美化、中西文混排调校与微润墨特效

    精选书卷衬线长文、现代无衬线界面与人文等宽代码字体组合，分层桥接中西文字重比例并在浅色纸面融入细腻活字微润墨效果（草墨石砚在 macOS 开启润墨，Windows 严格零晕墨保持清脆）。

  • 上下文迷你信息胶囊、Token 统计与一键热升级

    输入框底栏内嵌迷你信息胶囊（显示速率、首字延迟与上下文圆环，悬停可见详情），系统设置集成「Token 统计」面板；内核 core/ 与用户配置 user/ 分离，支持双镜像一键原地热升级（upgrade）且不覆盖个人设置。

  • 纯粹克制与非侵入式低风险设计

    仅通过本机回环（127.0.0.1）CDP 通道向前端渲染层注入 CSS 样式与静态汉化词条，不解包、不修改 app.asar 安装包，完整保留客户端官方数字签名与系统公证；内置的 Token 统计与指标胶囊仅离线只读解析本机已落盘的 SQLite 会话库，不读取系统钥匙串与 OAuth 凭据、不调用 Google 内部私有配额接口（如 retrieveUserQuotaSummary）、不伪造客户端身份标识（User-Agent / clientInfo），亦不涉及任何 CDP 对话流自动化操控、网络代理拦截、多账号切换或跨工具目录扫描等其他技术手段（注：纯前端运行时渲染层注入虽不涉及网络请求与鉴权凭据交互，但在客户端服务条款字面上仍属未显式授权的本地修改灰区，并非绝对零风险，支持随时一键彻底卸载并无损还原）。

安装与快速上手

新用户首次安装：复制引导词发给你的 AI Agent（推荐）

支持 Antigravity 2.36.0+ / 2.35.x / 2.34.0+，环境要求 Node.js >= 22.0.0（推荐 >= 22.13.0）。必备字体支持脚本从 Cloudflare R2 / GitHub 多源自动下载注册；国内网络如较慢，可直接在「资源下载页」打开飞书免代理分流页下载后交给脚本安装。

AGENT PROMPT · 首次部署 v6.1.0 
请帮我克隆 https://github.com/Anarcadia/chuanban-antigravity-theme-patch.git（或读取我已下载解压的补丁目录），先完整阅读仓库内的 SKILL.md，再按以下顺序部署并处理边缘情况：
1. 若本机有 nvm / fnm / volta，优先切换至 Node >= 22.13.0 执行命令；运行 node install.mjs doctor 检查 fonts.allRequiredInstalled 与 fonts.unregisteredWarning。
2. 若缺少字体（或 Windows 提示有未写注册表的用户字体）：
   - 若我本地已下载好字体目录或 .zip，直接执行 node install.mjs install-fonts --from "<字体目录或.zip路径>"；
   - 若本地尚未下载，直接执行 node install.mjs install-fonts --auto-download（Windows 检出旧版 SuperTTC 请追加 --retire-super-ttc）；
   - 若中国大陆终端下载遇阻或较慢，提示我打开飞书国内免代理字体页（https://www.feishu.cn/wiki/V2lbwB8ykiLLXrkzY41cXjQ1nXc）下载全部字体到同一目录后再运行 install-fonts --from（macOS 缺少更纱也可用 brew install --cask font-sarasa-gothic）。
3. 运行 node install.mjs install 完成安装（默认启用 "morandi" 莫兰迪风格）。
4. 若输出 cdpStatus 为 "missing_opt_in_flag" 且你当前正在 Antigravity 内部会话中，请勿强行重启自断会话，提示我空闲时运行 node ~/.gemini/antigravity/theme-patch/install.mjs relaunch（或手动重开客户端）。
5. 端口就绪后运行 node install.mjs verify，确认 "ok": true、"hasStyle": true 且 fonts.allRequiredInstalled: true 即完成验收。

老用户无损升级至 v6.1.0（支持 upgrade 一键增量热升级）

已安装 >= v6.0.7 的用户可直接在「系统设置 → 外观界面」底部点击「立即热升级」（或运行 node install.mjs upgrade）原地秒升；更早版本复制下方指令升级一次即可保留 user/ 自定义配置并接入热升级。

AGENT PROMPT · 升级至 v6.1.0 
请帮我拉取最新的 https://github.com/Anarcadia/chuanban-antigravity-theme-patch.git（或读取最新解压目录），阅读 SKILL.md 后直接运行 node install.mjs install 升级至 v6.1.0。若端口未开启且你正在 Antigravity 内部会话中，请提示我空闲时执行 relaunch，就绪后运行 node install.mjs verify 验收。
开发红线与合规边界：本仓库 main 分支坚决不加入自动操控对话流、绕过配额、拦截网络请求、读取 OAuth 凭据或修改客户端二进制签名的功能。本项目为独立非官方社区视觉增强补丁，与 Google 无关，随时可运行 node install.mjs uninstall 彻底还原。
